COMMON PATTERNS

真正反复出现的版面共性

结论来自32个主页的同口径封面联系表与11条视频时间轴，其中30个为正式行业样本、2个为用户指定补充。所有“内容观点”变量被排除，只保留视觉呈现。

01 / IDENTITY

先固定人，再固定模板

大多数账号把脸作为第一视觉锚点：半身或近景占画面约35%–60%，眼睛靠近上三分之一。即使换场景，人物发型、服装气质和出镜距离仍保持连续。

02 / TITLE ZONE

标题区固定，字组按句替换

标题最常落在上中区或胸口到下三分之一，通常2–4行。少数账号故意用遮眼横条形成辨识度，但会牺牲人物亲近感。

03 / COLOR

白黄负责阅读，红色只做重点

主标题常用白/黄，黑描边或暗底保证对比；红色只强调数字、否定词或关键短语。蓝、绿、枣红通常作为长期固定品牌块，不频繁换色。

04 / TYPOGRAPHY

粗黑体优先，层级比字体花样重要

作品标题平均约29个汉字；43%含数字，33%使用问句。画面大字通常控制在两种字号和两种字重内。

05 / MOTION

动效不复杂，稳定位置持续刷新

常见做法不是整屏飞字，而是固定字幕区内按语义块淡入、弹入或硬替换。人物口播越稳定，字组动效越需要承担节奏。

06 / INSERTS

证据图用硬切，氛围图用叠景

手机截图、表格、新闻页多采用全屏/半屏硬切；生活场景用B-roll；港险和城市类账号常把人物抠像叠在实景上。插图通常不超过一个主信息层。

5 VISUAL ARCHETYPES

五种可复用视觉母版

不是让所有账号长得一样，而是先选择一个主母版，再用10%–20%的次母版保持新鲜感。

固定棚拍口播

固定背景、机位、服装气质与字幕区。适合高频、稳定、低制作成本。

黑金专业卡

暗背景、大标题、人物半身与数据卡。专业感强，但要避免全页过度压黑。

生活纪录片

家庭、工作、出行场景连续，标题克制。个人信任更强，视觉统一依赖人物本身。

抠像知识卡

人物抠像叠城市/资料背景，大字占上半区。信息密度高，制作要求也更高。

证据图混剪

口播为主，截图、表格、手机界面做硬切。适合建立“有依据”的视觉感。

METHOD & LIMITS

口径、排除与边界

怎么选出30+2个

  1. 搜索16个作品主题，同时看综合与高赞结果，共记录494条作品。
  2. 从作品反查294位作者；昵称只用于去重和确认主页，不用于判定赛道。
  3. 正式样本逐页抽查最近30条，保险相关内容占比不足60%即排除。
  4. 再排除公司官方号、机构矩阵、多人轮岗与个人身份无法核验账号。
  5. 正式30人按严格头部与垂直代表分层；“微易老周”和“财商-黄永鳌”为用户指定补充，单独标识且不挤占正式名单。后者因主页保险占比约10%，只研究指定的保单系列版面。

本报告不做什么

  • 主题分类只用于确认主页主讲方向，不评价保险观点或产品。
  • 不抓评论，不分析销售话术、咨询承接或转化。
  • 单条保险爆款不能让泛生活、汽车或泛财经账号进入正式样本。
  • 可见点赞来自主页卡片，不能替代平台后台数据。
  • 封面不足30张时按实际可见数量记录，不补造。

REUSABLE MASTER PROMPT

最终研究 Prompt

这份 Prompt 已把“从作品反查作者”“主页保险内容≥60%”“30个都要研究”写成硬约束。

终极目标：建立“抖音保险从业者个人IP视觉与运营呈现数据库”，选取30个保险个人IP进行同口径横向研究，以严格头部为主，数量不足时把垂直代表单独分层；不选择公司官方号、机构矩阵号或多人轮岗号。

研究对象定义：
1. 严格头部：粉丝≥50万，或累计获赞≥300万；
2. 垂直代表：未达到严格线，但主页最近30条中保险相关作品占比≥60%，在细分赛道中具有稳定产出或鲜明视觉代表性，且个人身份可核验；
3. 个人IP：固定个人、固定家庭叙事或稳定个人化角色。公司认证可以是从业机构背书，但账号显示名、出镜主体和表达方式必须指向个人；
4. 最终必须研究30个账号，不允许从30个候选中只挑1个深挖。

抓取与样本：
- 禁止把账号昵称或昵称中的“保险、养老、理财”等字样作为主要发现方式；
- 先搜索不少于16个作品主题，包括百万医疗、重疾理赔、家庭风险、养老金、保单架构、财富传承、香港保险、拒赔处理、社保养老和少儿保障；
- 同时采集综合排序与最多点赞结果，从视频反查作者主页；昵称只用于去重和身份确认，不用于决定是否入选；
- 对候选逐页核验URL、认证、粉丝、获赞、作品数、最近更新时间，并抽查最近30条作品；
- 保险及相邻主题作品占比必须≥60%，否则排除；单条保险爆款不能把泛生活、汽车或泛财经账号算作保险IP；
- 每个入选账号保存最近30张可见封面并生成5×6联系表；
- 统计固定身份覆盖、模板统一度、标题区、人物比例、主配色、字体层级；
- 从不同视觉母版中选10条视频。高表现阈值为：账号最近30条可见点赞P90且点赞≥1万；小体量账号允许使用账号内P90，并明确标记；
- 10条视频必须风格不同，分析开头3秒、固定字幕区、字组动效、截图/插图插入、B-roll、转场和硬切频率。

严格边界：
- 只研究账号视觉定位、封面版式、标题文字形式、字体层级、字幕位置、文字动效、插图/视频插入方式、镜头与剪辑节奏；
- 不分析保险观点、产品好坏、脚本观点、评论区、销售话术、转化路径和私域运营；
- 数据缺失必须写“未获取”，不得猜测；降低门槛必须分层说明，不得把小号伪装成百万级头部。
